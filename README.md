# Pixar Films: Data Analysis Using T-SQL and Azure

**Team Members:** Laura Herrera & Angel Colonia

**Project:** Final Project — Azure SQL Database, T-SQL & GitHub

## 1. Project Overview

Pixar Animation Studios has produced animated films that have influenced the entertainment industry for decades. Through this project, we aim to explore Pixar's film history and identify patterns in financial performance, audience reception, critical ratings, and Academy Award recognition.

Using Microsoft Azure SQL Database and T-SQL, we will analyze a relational database containing information about Pixar films. Our findings will be presented through SQL queries, data visualizations, and a final presentation.

## 2. Data Source

**Dataset:** Pixar Films

**Source:** [Maven Analytics — Pixar Films](https://mavenanalytics.io/data-playground/pixar-films)

The downloaded dataset contains six related data tables and one data dictionary.

| Table | Description |
|---|---|
| pixar_films | Film titles, release dates, runtimes, and ratings |
| box_office | Production budgets and box office revenue |
| public_response | Rotten Tomatoes, Metacritic, IMDb, and CinemaScore |
| academy | Academy Award categories and outcomes |
| genres | Film genres and subgenres |
| pixar_people | Directors, musicians, writers, and other contributors |

The six data tables contain 637 records in total. We will review the dataset's structure and determine whether additional data is needed to meet the project's size requirements.

## 3. Research Objectives

Our analysis will focus on four main objectives:

**Objective 1: Financial Performance**
- Identify Pixar's highest-grossing films.
- Compare production budgets with worldwide box office revenue.
- Explore changes in financial performance over time.

**Objective 2: Audience and Critical Reception**
- Compare audience ratings and critic scores.
- Investigate relationships between film ratings and box office success.

**Objective 3: Film Characteristics**
- Explore performance differences across film genres.
- Examine the contributions of directors and other film personnel.

**Objective 4: Historical Trends and Recognition**
- Analyze trends across Pixar's release history.
- Examine Academy Award nominations and wins.
